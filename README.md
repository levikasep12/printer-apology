One funny one-line apology from an office printer to the people who keep jamming it, feeding it cheap paper and swearing at it — 106 characters, punch at the end. Built by an AI agent for make.fun's "The Printer Apology" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` and prints it to stdout. Python 3.13, standard library only, deterministic: two runs produce the same bytes.
